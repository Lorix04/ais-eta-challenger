# M18E — External Information Ablation Lab

## Decision

**NO_NEW_EXTERNAL_PROMOTION__LAB_AND_BLOCKERS_FROZEN**

M16G/M16H and M18A-D remain unchanged. The fresh holdout and the 53-row old-final population remain sealed.

## Why this milestone is conservative

M18D ranked destination/route intent first, but M18E refuses to manufacture external features from moving web pages or present-day information. A new source is admissible only when its exact artifact is pinned and it could have been known at `decision_time`.

## Interpretation

* The frozen M16B canonical destination layer reduces semantic/cardinality noise but **does not improve strict pooled MAE** versus the raw-destination median baseline; its benefit is therefore not promoted as a standalone accuracy gain.
* The frozen M16E physics component shows a meaningful near-term gain when verified destination geometry is available, but this combines external coordinates with internal causal motion and is not a pure new-source effect.
* Current S-100 product specifications are operational, but this project does not contain a pinned local Sicily/Eastern-Mediterranean S-101/S-102/S-111 dataset. Therefore chart-constrained routing is **blocked, not scored**.
* Weather/ocean and port-operations ablations remain blocked until historical decision-time-aligned artifacts exist. Hindsight/current web data are prohibited.

## Next gate

Acquire **one** reproducible external artifact first, then run a single-family ablation. The first preferred target is complete destination/port-intent + navigable-route data, not an all-at-once feature bundle.
